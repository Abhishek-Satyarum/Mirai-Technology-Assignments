# The Multi-Modal Visual Novel

An AI-powered **Choose Your Own Adventure** game built with **Streamlit**, **Google Gemini**, **Pollinations AI**, and **gTTS**. Every choice generates a new story, AI artwork, and narrated experience.

---

## Features

- 🤖 AI-generated interactive stories
- 🎮 Dynamic choice-based gameplay
- 🖼️ AI-generated scene illustrations
- 🔊 Text-to-Speech narration
- 💾 Story history with Session State
- ⚡ Cached Gemini client
- 🛡️ Graceful error handling

---

## Tech Stack

- **Frontend:** Streamlit
- **AI Model:** Google Gemini 2.5 Flash
- **Image Generation:** Pollinations API
- **Text-to-Speech:** gTTS
- **Language:** Python

---

## Getting Started

```bash
git clone https://github.com/Abhishek-Satyarum/The-Multi-Modal-Visual-Novel.git

cd The-Multi-Modal-Visual-Novel

pip install -r requirements.txt

streamlit run app.py
```

Create a `.env` file:

```env
GEMINI_API_KEY=YOUR_API_KEY
```
